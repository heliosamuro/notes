## Week 2 - Bits and Bytes
- Long term memory, called storage or disk: Usually slower and optimized to read or write large chunks of data at a time.
- Volatile working memory, usually called RAM: RAM = Random Access Memory; it’s fast for reading from any location.

## Week 3 - Markup Languages
- JSON stands for JavaScript Object Notation.
- XML stands for eXtensible Markup Language.
- JSON is newer and taking over, but XML is still used a lot.
- Both are text-based formats used to serialize structured data, they are intended to be read by computer software, but still be human-readable.

## Week 4 - Keyboards and Editors
- RegEx (Regular Expressions): A whole language for creating search patterns.
- The basics:
.   matches any character
[abc] – matches any of the listed characters
[a-z] – matches any lower-case letter
[0-9] – matches any digit, so does \d

## Week 5 - CLI (Command Line Interface)
Some useful Linux/MacOS Commands:
- `ls` – list files in current directory
- `pwd` – print working directory
- `cd` - change directory
- `cat`, `less` – show contents of a text file
- `cp`, `mv`, `mkdir` – copy & move files, create a directory
- `ping` – ping a server over the network
